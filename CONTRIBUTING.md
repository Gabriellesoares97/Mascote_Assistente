## 🇧🇷 Português (Brasil)

# Contribuindo com o Mascote Assistente

Obrigado por querer ajudar! Como é um projeto de arquivo único (sem build, sem dependências),
contribuir é bem direto.

### Testando localmente

1. Baixe/clone o repositório.
2. Abra `index.html` direto no navegador, ou sirva a pasta com um servidor simples:
   ```bash
   python3 -m http.server 8000
   ```
3. Teste a mudança manualmente nas telas afetadas — inclua o cenário de mobile (a maior parte do
   público usa o app no celular).

### Estilo de código

- HTML, CSS e JavaScript puro, sem frameworks nem bibliotecas externas — é intencional, pra manter
  o app leve e sem dependências.
- Textos visíveis para a pessoa usuária devem passar pelo sistema de tradução (`I18N`/função `t()`/
  `tf()`), não ficar hardcoded em português no meio do código.
- Siga o tom acolhedor já estabelecido nas mensagens do mascote — evite linguagem que cobre
  produtividade ou faça a pessoa se sentir mal por não ter completado algo.

### Reportando bugs

Abra uma *issue* descrevendo:
- O que você esperava que acontecesse.
- O que aconteceu de fato.
- Passos para reproduzir (inclua o navegador/dispositivo, se possível).

### Pull Requests

- Descreva a mudança e o motivo.
- Se alterar algo visual, uma captura de tela antes/depois ajuda bastante.
- Mudanças em textos do app devem atualizar os 4 idiomas (`pt-BR`, `pt-PT`, `en-US`, `es-ES`) — ou
  ao menos o `pt-BR`, sinalizando na descrição do PR que as outras traduções ainda faltam.

## 🇺🇸 English

# Contributing to Mascote Assistente

Thanks for wanting to help! Since this is a single-file project (no build step, no dependencies),
contributing is pretty straightforward.

### Testing locally

1. Download/clone the repository.
2. Open `index.html` directly in your browser, or serve the folder with a simple server:
   ```bash
   python3 -m http.server 8000
   ```
3. Manually test your change on the affected screens — include the mobile scenario (most of the
   audience uses the app on their phone).

### Code style

- Plain HTML, CSS, and JavaScript, no frameworks or external libraries — that's intentional, to
  keep the app light and dependency-free.
- Text visible to the person using the app must go through the translation system (`I18N`/the
  `t()`/`tf()` functions), not stay hardcoded in Portuguese in the middle of the code.
- Follow the warm tone already established in the mascot's messages — avoid language that pushes
  productivity or makes someone feel bad for not finishing something.

### Reporting bugs

Open an *issue* describing:
- What you expected to happen.
- What actually happened.
- Steps to reproduce (include your browser/device, if possible).

### Pull Requests

- Describe the change and why you made it.
- If it changes something visual, a before/after screenshot helps a lot.
- Changes to app text should update all 4 languages (`pt-BR`, `pt-PT`, `en-US`, `es-ES`) — or at
  least `en-US`, flagging in the PR description that the other translations are still missing.
